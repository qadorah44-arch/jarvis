# JARVIS — تطبيق Android

مساعد صوتي ذكي بصلاحيات الهاتف: اتصال، رسائل، جهات الاتصال، منبّهات، مؤقتات، فتح التطبيقات، الكشاف، الصوت، التقويم.
العقل: Groq (مجاني) أو Claude (مدفوع) — يُختار من الإعدادات داخل التطبيق.

## البناء (من الهاتف)
1. أنشئ مستودعاً جديداً على GitHub باسم `jarvis-app`.
2. Add file ← Upload files ← ارفع كل الملفات (ما عدا build.yml).
3. Add file ← Create new file ← اكتب الاسم: `.github/workflows/build.yml` ← الصق محتوى build.yml ← Commit.
4. انتظر 5–8 دقائق، ثم افتح **Releases** في صفحة المستودع ← نزّل `JARVIS.apk` ← ثبّته.
5. إن فشل البناء: Actions ← آخر تشغيل ← انسخ رسالة الخطأ الحمراء وأرسلها لـ Claude.
